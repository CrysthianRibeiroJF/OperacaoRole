# Glossário

Vocabulário do produto. Use estes termos de forma consistente em telas, tickets e código.

| Termo | Significado |
|---|---|
| **Rolê** | O evento em grupo (bate e volta, viagem, churrasco...). |
| **Operação Rolê** | Nome do app e do ciclo de organização. |
| **Faísca** | A fase 1 do ciclo (0–48h): proposta lançada e cronômetro rodando. Também a persona de quem tem a ideia. |
| **Idealizador** | Cargo de quem cria o rolê, define o quórum e encerra votações. |
| **Andorinha** | Cada pessoa que confirma "Tô Dentro" para formar a massa crítica. "3 andorinhas" = quórum padrão. |
| **Massa crítica / Quórum** | Número mínimo de confirmações para o rolê virar oficial (padrão 3, faixa 2–6). |
| **Proposta Relâmpago** | Cartão fechado com destino, data, teto de gasto e prazo. |
| **Pega ou Larga** | Princípio da proposta fechada: sem perguntas abertas. |
| **Rolê Confirmado** | Estado após atingir o quórum. Não implica sinal pago (D-008). |
| **Tô Dentro / Passo** | Respostas à proposta. |
| **Tropa** | Participantes confirmados sem cargo de General. |
| **Observador (Em Cima do Muro)** | Quem só visualiza até decidir confirmar. |
| **General (da Base, da Frota, de Suprimentos, do Tesouro)** | Cargos táticos com responsabilidade e permissão por domínio. |
| **Patente** | Sinônimo de cargo. |
| **Janela do Sinal** | Período em que o confirmado deve pagar o sinal e anexar o comprovante. |
| **Sinal** | Entrada paga por Pix para garantir a vaga. |
| **Trava Anti-Pipoca** | Regra que só dá direito à vaga a quem pagou o sinal. |
| **Lista de espera** | Fila de quem não pagou o sinal a tempo ou entrou depois da lotação. |
| **QG do Rolê** | Dashboard do evento após confirmar presença, com abas. |
| **Mural da Base** | Cartão fixo com Wi-Fi, código do cadeado, check-out e regras. |
| **Cofre** | Aba financeira do QG. |
| **Cota Global / Etílica / Carnívora / Veículo** | Categorias de rateio por perfil de consumo. |
| **Fechar Conta do Rolê** | Ação do Tesoureiro que calcula os saldos finais. |
| **Chato Oficial** | O próprio app agindo como cobrador impessoal via alertas automáticos. |
| **Missão Pendente** | Alerta de cargo ou item sem responsável perto do rolê. |
| **Pipoca** | Quem diz que vai e some no dia. |
| **Calote** | Dívida não paga no acerto final. |
| **Mercado** | Aba com a lista de compras do rolê, dividida por categoria. |
| **Eu levo** | Microtarefa: a pessoa assume um item da lista. |
| **Frota** | Conjunto de carros do rolê, cada um com lugares e bagagem. |
| **Tralhas** | Itens grandes (cooler, guarda-sol, caixa de som) alocados a um carro. |
| **Ordem nº** | Código curto do convite, exibido como número de série do bilhete. |
| **Bilhete / Carimbo** | Elementos visuais do app: o bilhete representa um rolê ou saldo; o carimbo aparece só em decisões (Confirmado). |
| **Código de recuperação** | Código de 16 caracteres entregue no cadastro; único jeito de recuperar a conta sem SMS ou e-mail. |
| **Aparelho conectado** | Uma sessão ativa da conta (ex.: "Chrome no Android"), que a pessoa pode desconectar. |
| **Central da conta** | Área `/perfil`: dados pessoais, avisos, segurança e privacidade. |
| **Quarto / Cama** | Espaço da casa com camas; cada confirmado pega uma, com a trava do sinal. |
